# Ảnh demo

anh_toi.png là ảnh minh họa lấy từ bộ LOL-v2-real cục bộ đã có trong dự án. anh_sang.png là kết quả thực chạy checkpoint model_current.pt, không phải ảnh GT hoặc ảnh tạo sinh.

Mở giao diện bằng start_app.cmd, chọn anh_toi.png và nhấn Tăng sáng. Kết quả được tự lưu vào outputs/images. Ảnh demo có kích thước 600×400, giữ nguyên kích thước khi cạnh tối đa là 1280.
