# 1.1 Cấu trúc dự án

Code được chia theo trách nhiệm. `kind_enhance` là package chính; `tools` chứa công cụ chạy thực nghiệm, đánh giá và kiểm chứng. Điểm vào giao diện là `app.py`; mở file và bấm Run Python File hoặc chạy bằng Python của dự án.

`models` mô tả mạng; `inference` thực thi pipeline đã duyệt; `training/losses` chứa các hàm mục tiêu dùng khi học. Một file loss không có nghĩa loss đó đang được dùng trong sản phẩm: công thức được chọn bởi cấu hình và script huấn luyện. `research` giữ tiện ích phục vụ thử nghiệm, không tự chạy khi mở giao diện.

`data` ở gốc là manifest; `kind_enhance/data` là code đọc dataset. `outputs` là kết quả ứng dụng, còn `experiments` là bằng chứng thực nghiệm đã có. Mã snapshot trong `experiments` giữ đường dẫn lịch sử để bảo toàn provenance; bảng di chuyển code hiện tại nằm tại `outputs/checks/code_reorganization.json`.

Suy luận ảnh mới chỉ cần checkpoint/cấu hình, không cần dataset/GT. Các môi trường `.venv`, `.runtime311`, dataset và tệp nén gốc được giữ tại vị trí hiện có. Không tải thư viện hoặc dữ liệu khi tổ chức code.

Kiểm tra từ thư mục gốc:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests
.\.venv\Scripts\python.exe -B -m kind_enhance doctor
.\.venv\Scripts\python.exe -B tools/verification/check_project.py
```
